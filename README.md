# 🐉 Dungeon Adventure Game

A text-based RPG battle game built using **C++** to practice Object-Oriented Programming (OOP) concepts.

Step into the dungeon, face powerful enemies, and experience a battle adventure through the terminal!

## 🎮 About the Project

Dungeon Adventure is a console-based game where players enter the dungeon, view their character stats, and battle against enemies. The project is designed to strengthen C++ fundamentals and demonstrate how OOP concepts can be used to build a simple game.

## ✨ Features

- 🧙 **Custom Player Name** — Enter your own adventurer name.
- ❤️ **Health System** — Track player and enemy health.
- ⚔️ **Attack Power** — Each character has an attack value.
- 👹 **Enemy System** — Battle against enemies with different stats.
- 🖥️ **Console Interface** — Simple, terminal-based gameplay.
- 🧩 **OOP-Based Design** — Organizes game entities using C++ classes.

## 🛠️ Tech Stack

- **Language:** C++
- **Concepts:** Classes, Objects, Encapsulation, Functions
- **Tools:** Git, GitHub, VS Code

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/shristibajpai/dungeon-game-.git
```

### 2. Navigate to the Project Folder

```bash
cd dungeon-game-
```

### 3. Compile the Game

If your source file is named `main.cpp`, run:

```bash
g++ main.cpp -o dungeon
```

### 4. Run the Game

On Windows:

```bash
.\dungeon.exe
```

On Linux or macOS:

```bash
./dungeon
```

> Make sure a C++ compiler, such as GCC, is installed before compiling.
